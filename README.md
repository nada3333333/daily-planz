## Technologies utilisees
- Java 17 + Spring Boot
- Thymeleaf
- MySQL 8
- Maven

## Prerequis
- Java 17+
- Maven 3.8+
- MySQL 8+

## Instructions de lancement
1. git clone https://github.com/nada3333333/daily-planz.git
2. CREATE DATABASE dailyplanz;
3. cd daily-planz
4. mvn spring-boot:run
5. Ouvrir http://localhost:8080
